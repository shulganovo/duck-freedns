# Changelog

Все значимые изменения проекта будут отражаться в этом файле.

## [1.0.0] - 2026-07-13

### Добавлено

- автоматическое обновление DuckDNS;
- автоматическое обновление FreeDNS;
- проверка изменения внешнего IP;
- проверка обновления DNS через `dig`;
- повторная попытка обновления;
- автоматическая установка `curl` и `bind-dig`;
- интерактивный установщик;
- автоматическое создание cron-задачи;
- отдельный файл конфигурации;
- русскоязычная документация.
